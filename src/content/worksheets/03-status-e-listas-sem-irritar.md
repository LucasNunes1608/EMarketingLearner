"________________________________________________________________________________"

## 5. Sinais de que você está incomodando

- [ ] Ninguém responde os últimos três avisos
- [ ] Três ou mais pessoas pediram para sair na mesma semana
- [ ] As visualizações do status caíram semana após semana
- [ ] Cliente antigo parou de responder do nada

Se marcar dois ou mais, reduza a frequência antes de perder o resto.

## 6. Lista de conferência

- [ ] Postei três status hoje mostrando o processo
- [ ] Criei pelo menos duas listas separadas por interesse
- [ ] Pedi para os clientes salvarem meu número
- [ ] Coloquei esse pedido na mensagem de saudação
- [ ] Escrevi o próximo aviso de cada lista com o motivo
- [ ] Toda mensagem de transmissão termina com a saída
